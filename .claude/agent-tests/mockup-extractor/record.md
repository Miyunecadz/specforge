## 1. Design (from intake)

Intent confirmed by BUILD_SPEC.md §9.1 and §8 (user-approved plan, 2026-10-11).

| Fact | Answer |
|---|---|
| Job (one sentence) | Extracts one captured mockup into a traceable `inventory.json`. |
| Inputs | Run ID and run directory (from the orchestrator, Stage 3). |
| Output and who uses it | `inventory.json` (+ optional warnings file) for gap-analyst and later stages; a 5-line summary to the orchestrator. |
| Delegate when | "extract the inventory for run <run-id>", "extract the UI inventory from the captured mockup in runs/<id>" |
| Do NOT delegate when | design/accessibility review, writing requirements or specs, capturing a URL, mockups outside a run directory |
| Pushback given at intake | none: job and tools already least-privilege in §9.1 |

**Tools**

| Tool | Step that needs it | Why a smaller tool will not do |
|---|---|---|
| Read | 1, 2, 6 (manifest, page text/HTML/aria, screenshots; read back) | needed to see the capture, including images |
| Write | 6, 7 (create inventory.json, warnings file) | creating new files; Edit cannot create |

Tools considered and refused: Glob/Grep (manifest lists every file), Bash (nothing to run), WebFetch (never follows URLs).
