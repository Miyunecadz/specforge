Dialog focus management (fixture guidance)

Published 2025-03-01.

When a modal dialog opens, move keyboard focus to the first focusable element inside the dialog, or to the dialog heading when the first control is destructive.

When the dialog closes, return focus to the element that opened it, unless that element no longer exists, in which case move focus to a logical place in the page.
